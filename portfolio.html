Web Administration, Domains & Cloud Hosting

Website Administration

Ongoing care for live sites: WordPress core, theme and plugin updates, security hardening, backups, uptime checks, speed tuning, and content changes when you need them.

Domain Registration & Management

Register .com.au and international domains, transfer names between registrars, and keep renewals, DNS records, email routing and SSL certificates under control.

AWS & Google Cloud Hosting

Website hosting set up on Amazon Web Services or Google Cloud, from low-cost static S3 sites to full LAMP servers, with CDN, HTTPS and automated backups configured for you.

Move an existing website to faster or cheaper hosting without downtime — files, databases, mailboxes and DNS cut over together, with the old host kept live until it is proven.
